## 2. 怎么做的

```text
beats.mjs        249 张字幕卡（每卡 ≤2 行、按段均分时长）
   ↓
clips*.mjs       11 个镜头：window.renderAt(t) 的 canvas 绘制代码
   ↓  kit.mjs    统一色板 / 四档字号 / 缓动 / 字幕渲染器 / 环境运动
render-chunked   分块渲染（≤8s/块）→ ffmpeg 无损拼接
   ↓
music.js         原创配乐：4 情绪 × 4 和声进行 × Karplus–Strong 拨弦 + Schroeder 混响
sfx.js           48 条音效，按段内相对时间钉帧，按能量峰值对齐
   ↓
build.js         场景拼接 + 响度归一化（−16 LUFS）
   ↓
review.mjs       门禁六条腿 + 判例式审美准则 + 独立终检五节报告
```

**为什么分块渲染**：headless Edge + CDP 单次渲染实测在 ~1000 帧附近会卡死（队友在 1022 帧
断连，我自己也复现过）。切成 ≤8 秒（240 帧）的块后，全部 11 个镜头 38 分钟渲完，且任一块
失败可以单独重试。

**为什么字幕烧在镜头里**：没有旁白，字幕就是配音。烧在画布上才能做到「关键词金色、无底框、
居中单行、y=91.5%」，与参考片的排版一致；用 `build_video` 的 captions 会带底框且无法上色。

## 4. 诚实记录：验收门禁里两条互相拉扯的腿

这是本次制作最值得记下来的一件事。门禁的六条腿里有两条在本片上是**互相拉扯**的：

| 腿 | 判据 | 对本片的要求 |
|---|---|---|
| 静帧比例 | 静帧 ≥25% 的帧 | 关键信息落定后要真的**停住**，让观众读 |
| 静止空档 | 不允许 ≥3s 完全不动 | 又不许停超过三秒，否则像卡住 |

数学科普片的常态是「画好了，等观众读 3–6 秒」——第一版实测：静帧 62%、最长静止 **3.58s**
（死在这一条）。我把一条环境扫光带铺满全片后：最长静止降到 0.5s，但静帧掉到 **7%**
（死在另一条）。两个极端都不对。

最终解是把扫光带做成**脉冲**：每 2.6 秒里只出现 1.1 秒。于是
「始终有静帧可数」+「没有任何一段超过 2.6 秒完全不动」同时成立，视觉上它读作一次克制的
光掠过，而不是故障。这个参数（2.6 / 1.1）就是两条门槛之间唯一的窗口。

其余没过的腿，原因照实写：

- **镜头长度变异系数 0.235 < 0.25（WARN）**：11 段时长 40–98 秒是按内容分配的，不是等长节拍器，
  但确实低于门槛。要过这条得重排分段时长并重渲。
- **音频安静片段占比 1%（WARN）**：全片配乐是连续氛围床，没有真正的静音段；
  参考片同样如此（LRA 3.0）。要过这条得在几处插入刻意的静默。

另有一条是**检测器局限**，不是片子问题：

- **切点检测器看不见「暗场接暗场」的切点**，把全片报成 6–8 个等长假镜头（842/8≈105s）。
  所以节奏这条腿用作者标注的分镜表来量，不用检测器的猜测——`review.mjs` 里注明了这一点。

## 5. 事实与口径

第 9 段严格按「宣称 → 预印本 → 形式化检查 → 同行评审 → 社区接受」五级表述：
截至成片时，据公开报道形式化检查已过，**同行评审尚未完成**。片子里说的是
「数学界正在读两份稿子」，没有说「黎曼猜想被证明了」。

数字来自：π(10^n) 实测表、最大已知素数 2^136279841−1（4102 万位，2024）、
RSA-250/260 分解代价、前五个零点虚部、N(T) 计数公式、临界线上零点比例
1/3 → 2/5 → 41.6%、验证高度 3×10¹²（1.2363×10¹³ 个零点）。
